Frequently Asked Questions

Quick answers to common questions about Sonorium.

Why don't I hear any sound?

Common causes:

  • Speaker compatibility: The speaker doesn't support HTTP audio streams
  • Network: Firewall blocking the stream, or speaker on different subnet
  • Volume: Channel volume or master gain set to 0
  • Device muted: Physical speaker is muted

Try playing to a different speaker to isolate the issue. Check the Sonorium logs for errors.

My speakers aren't showing up

Sonorium discovers speakers from Home Assistant's media_player entities:

  • Verify speakers are set up as media_player entities in HA
  • Check they aren't disabled in Sonorium Settings
  • Try Refresh from HA (or Rescan network) on Settings → Speakers

Speakers must support HTTP audio streaming (Chromecast, Sonos, DLNA work great).

What audio formats are supported?
  • .mp3 — Most compatible, recommended
  • .wav — Uncompressed
  • .flac — Lossless
  • .ogg — Open format

Use MP3 at 128-320kbps for best results. Longer tracks (1-10 min) loop more seamlessly.

What does "Interval" do?

Interval controls how often a track is heard in the mix (0-100%). Before 1.5.0 it was called Presence or "How often".

  • Intermittent: Interval sets the wait between plays
  • Ebb & Flow: Interval sets how much of the time it's heard
  • In a group: Interval sets how fast a track's weight wears off

For occasional sounds like thunder or bird calls, try 20-40%.

What are the playback modes?
  • Background: plays all the time, looping smoothly. Rain, wind, a fire.
  • Intermittent: plays once, then goes quiet before playing again. Interval sets the wait. In a group, the group decides when it plays. Bird calls, a thunder crack, a door.
  • Ebb & Flow: fades in, plays a while, fades out, then stays quiet before coming back. Interval sets how much of the time it's heard. Distant traffic, a passing crowd.
  • Auto: picks for you. Under 15 seconds plays Intermittent, longer plays Ebb & Flow. At 100% interval, either plays as Background.

Before 1.5.0, Background was Continuous, Intermittent was Sparse, and Ebb & Flow was Presence. Gapless loops a Background track without crossfade.

What is a group?

A group is a folder inside a theme. Each group has a Mode: Intermittent (the default), Merry-go-round or Intrusion. Groups replace the old per-track "Exclusive" switch.

  • Take turns: a group is a folder of tracks. In an Intermittent group only one plays at a time, never overlapping. Use it for sounds that shouldn't pile up, like thunder cracks or songs from one musician.
  • Group mode: Intermittent plays one track at a time with a gap; Merry-go-round makes a continuous bed.
  • Gap: after a track finishes, the group waits a random time in this range (minutes) before the next one starts. Different groups don't wait for each other.
  • Intermittent group: on its turn, a track plays its whole file once, start to finish, then hands over. Background and Ebb & Flow are for the ambience outside groups.
  • Merry-go-round: one file plays, then crossfades into another picked at random, never the same one twice in a row. Crossfade sets the overlap. One file crossfades into itself. Use 3 or more files of the same scene for a bed that never repeats the same way.
  • Intrusion group: a group in Intrusion mode, marked 🔗. Its tracks keep their own mode and settings, and it can hold files linked from other themes.
  • Weight: each time a track plays, it gets heavier and is less likely to be picked next. The weight wears off as other tracks play. The same track never plays twice in a row.
  • Interval: how fast a track's weight wears off. Higher comes back sooner; lower plays less often.
  • Deleting a group: keeps its files; they move back into the theme.
How do I blend two themes?

Use an intrusion. It brings files from another theme into this one without copying them, and a preset turns them on.

  • In the Theme Editor, add a group and set its Mode to Intrusion.
  • Open the group's ⋯ menu and pick Add from another theme. Pick a theme, preview its files, tick the ones you want and click Add.
  • Linked files start muted. Make a preset that turns them on, and turns off what they replace, then click Save Theme.

Example: a Campsite theme links rain from a Rainy Day theme. Its "Rain" preset turns the rain on and mutes the crickets. Pick it on a channel and the rain fades in while the crickets fade out.

A preset that turns intrusion tracks on shows ⚭ (after the ★ of the default preset). A linked file whose source is gone shows Missing. Moving a linked file to a normal group asks first, then copies it in, and exports copy linked files in.

Why does my theme go quiet between loops?

Some recordings fade in at the start and fade out at the end. Looped, the sound drops each time the file ends.

Put the file in a group, set the group's Mode to Merry-go-round, and set its Crossfade at least as long as the file's fade. A single file crossfades into itself, so the next pass is already playing while this one fades. With 3 or more recordings of the same scene, the bed never repeats the same way.

Can two channels play the same theme with different presets?

Yes. Each channel keeps its own preset, so changing the preset on one channel doesn't change the other. Tracks a preset turns on or off fade in or out over 3 seconds.

Does it work with Sonos/Google Home/Alexa?

Yes! Any speaker that's a media_player in Home Assistant and supports HTTP streaming:

  • Sonos: Full support
  • Google/Chromecast: Works great
  • Amazon Echo: Requires extra setup
  • DLNA/UPnP: Most network speakers work
  • AirPlay: Works with AirPlay devices
Where can I get ambient audio files?
  • Included themes: Sleigh Ride, Tavern and "A Rainy Day... Or is it?" come with Sonorium
  • Freesound.org: Large free sound library
  • Ambient-Mixer.com: Downloadable ambient soundscapes
  • YouTube Audio Library: Free ambient tracks
  • Record your own: Nature sounds, rain, etc.
Will standalone apps support network speakers?

Yes! Network streaming is on the roadmap for all standalone versions:

  • Windows, macOS, and Linux apps
  • Docker container

Planned support includes Chromecast, DLNA/UPnP, and AirPlay. Currently the Windows app plays through local PC audio.

Is Sonorium really free?

Yes! Sonorium is completely free and open source (MIT license). It's a fork of Amniotic by fmtr.

Source code is on GitHub. Contributions welcome!

How do I report a bug?

Open an issue on GitHub:

  • Report a Bug
  • Request a Feature

Include your setup details, steps to reproduce, and any error logs.

The Sonorium version and install type (Home Assistant app or Docker) are shown at the bottom left of the menu. On a phone, open the menu with the button in the top bar.
