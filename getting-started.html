Getting Started

Pick how to install Sonorium. Every path ends at the same documentation.

Sonorium plays ambient sound, such as rain, a forest or a busy tavern, on the speakers in your home. It mixes several recordings and keeps changing how each one plays, so the sound doesn't loop noticeably.

Sonorium runs on a computer that stays on, and you use it from a web page on any phone, tablet or computer in your home. There are three ways to install it. Pick the one that fits the machine you have; each has a complete guide, and all three end at the same place: Sonorium's documentation.

Not sure? If you already have Home Assistant OS, use the Home Assistant app. If you have Home Assistant in Docker (Container), use Docker and link it to Home Assistant.

Every path, step by step

  1. Home Assistant app: the Mosquitto broker, the repository, installing, the options, starting, the sidebar, Home Assistant's users, updating and uninstalling.
  2. Docker: the folders and compose file, starting, the first admin account, linking Home Assistant and MQTT, running without host networking, updating and uninstalling.
  3. Windows: installing and starting Sonorium on a Windows PC.

What each path needs in detail: Requirements.

After installing

Once Sonorium is open in your browser, everything works the same on every install:

  1. Turn on your speakers.
  2. Make a channel and play it.
  3. Explore Themes, Presets and Sequences and Playlists.
